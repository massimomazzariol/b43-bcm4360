# Image credits

Image assets used by the project README are stored in this directory so
that repository clones and source archives remain self-contained.

## Original project material

The following files are original project material by Massimo Mazzariol:

- `rt-ac68u-testbench.jpg`
- `rt-ac68u-board.jpg`
- `rt-ac68u-revision.jpg`
- `validation-pass.png`

The hardware photographs document the ASUS RT-AC68U used during
development and validation.

The validation screenshot shows OpenWrt running the standard Linux
wireless command `iw dev wlan0 scan passive`. Network identifiers shown
by the scan have been redacted.
